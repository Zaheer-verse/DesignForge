# AI App Interface Example

## Request

```text
Use DesignForge to design an AI research assistant interface. It needs conversation history, source inspection, attachment handling, and clear error states. Prioritize trust and repeated daily use.
```

## Discovery Summary

- Page goal: support focused AI-assisted research.
- Audience: knowledge workers who need source traceability.
- Visual direction: calm workspace, strong reading ergonomics, restrained motion.
- Primary risk: hiding important provenance or error information.

## Expected DesignForge Behavior

1. Identify core workflows before visual styling.
2. Separate conversation, sources, and composer controls clearly.
3. Make file and citation states explicit.
4. Support keyboard navigation and screen reader landmarks.
5. Ensure long messages and narrow screens do not break layout.
6. Validate available build and accessibility checks.

## Representative Output Structure

- Conversation list or project sidebar
- Main transcript region
- Source/details panel
- Composer with attachment and submit states
- Empty, loading, error, and recovery states
- Reduced-motion-safe transitions

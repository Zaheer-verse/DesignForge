# Landing Page Example

## Request

```text
Use DesignForge to create a responsive landing page for a privacy-focused analytics product. The audience is technical founders. Keep the tone calm and credible, avoid fake metrics, and run the available build checks.
```

## Discovery Summary

- Page goal: explain value quickly and drive trial signups.
- Audience: technical founders who distrust vague marketing.
- Visual direction: restrained developer-tool polish, strong typography, minimal decorative effects.
- Primary risk: inventing unsupported claims about privacy, compliance, or adoption.

## Expected DesignForge Behavior

1. Inspect the existing app stack and scripts.
2. Establish typography, spacing, color, and component state rules.
3. Build a first screen with clear product category and value.
4. Use realistic copy without fake customer logos or metrics.
5. Verify responsive behavior and accessibility.
6. Report commands run and checks not run.

## Representative Output Structure

- Hero with literal product category and focused value proposition
- Product workflow section
- Privacy controls section
- Pricing or trial CTA if supported by project context
- FAQ with concrete answers
- Final QA report

# 3D Web Design

3D elements can create memorable, immersive experiences. They can also destroy performance and distract from content. Use 3D intentionally.

---

## 3D Decision Framework

### When to Use 3D

**Good reasons:**
- Product visualization (e-commerce, demos)
- Data exploration (spatial data, complex relationships)
- Brand expression (innovative, forward-thinking brands)
- Immersive storytelling (narratives, experiences)
- Spatial interfaces (AR/VR-inspired UI)
- Interactive demos (education, tutorials)

**Bad reasons:**
- "It looks cool"
- Everyone else is doing it
- To hide weak content
- Without performance consideration

### Technology Decision Tree

```
Need simple visual depth?
└─ CSS 3D transforms (perspective, rotateX/Y)

Need interactive card tilt?
└─ CSS perspective + JavaScript tilt

Need floating/pseudo-3D elements?
└─ CSS transforms + shadows

Need rotating product display?
└─ CSS 3D or lightweight Three.js

Need complex 3D scene?
└─ Three.js / React Three Fiber

Need particles/immersive?
└─ WebGL (lazy-loaded)

Need advanced shaders?
└─ WebGL / Three.js custom shaders
```

## CSS 3D Transforms

### Perspective

Create depth perception with perspective:

```css
.scene {
  perspective: 1000px; /* Distance from viewer */
}

.card-3d {
  transform: rotateY(15deg);
  transform-style: preserve-3d;
}
```

**Perspective values:**
- `200px` — Extreme depth (dramatic)
- `500px` — Medium depth
- `1000px` — Subtle depth
- `2000px` — Minimal depth

### 3D Card Flip

```css
.card-container {
  perspective: 1000px;
}

.card {
  position: relative;
  width: 300px;
  height: 400px;
  transition: transform 600ms;
  transform-style: preserve-3d;
}

.card.flipped {
  transform: rotateY(180deg);
}

.card-front,
.card-back {
  position: absolute;
  inset: 0;
  backface-visibility: hidden;
}

.card-back {
  transform: rotateY(180deg);
}
```

### Interactive Tilt Effect

```css
.tilt-card {
  transform-style: preserve-3d;
  transition: transform 150ms ease-out;
}

.tilt-card:hover {
  transform: perspective(1000px) rotateX(5deg) rotateY(5deg);
}
```

**JavaScript for mouse tracking:**
```javascript
const card = document.querySelector('.tilt-card');

card.addEventListener('mousemove', (e) => {
  const rect = card.getBoundingClientRect();
  const x = e.clientX - rect.left;
  const y = e.clientY - rect.top;

  const centerX = rect.width / 2;
  const centerY = rect.height / 2;

  const rotateX = (y - centerY) / 10;
  const rotateY = (centerX - x) / 10;

  card.style.transform = `perspective(1000px) rotateX(${rotateX}deg) rotateY(${rotateY}deg)`;
});

card.addEventListener('mouseleave', () => {
  card.style.transform = 'perspective(1000px) rotateX(0) rotateY(0)';
});
```

### Floating Elements

```css
.floating {
  animation: float 6s ease-in-out infinite;
}

@keyframes float {
  0%, 100% { transform: translateY(0) rotate(0deg); }
  50% { transform: translateY(-20px) rotate(3deg); }
}
```

## Three.js / React Three Fiber

### When to Use

- Complex 3D scenes with multiple objects
- Realistic lighting and materials
- Interactive 3D objects
- Particle systems
- Custom shaders
- Animations beyond CSS capabilities

### React Three Fiber Setup

```jsx
import { Canvas } from '@react-three/fiber';
import { OrbitControls, Box } from '@react-three/drei';

function Scene() {
  return (
    <Canvas>
      <ambientLight intensity={0.5} />
      <pointLight position={[10, 10, 10]} />
      <Box args={[1, 1, 1]}>
        <meshStandardMaterial color="orange" />
      </Box>
      <OrbitControls />
    </Canvas>
  );
}
```

### Performance Optimization

**Lazy Loading**
```jsx
import { lazy, Suspense } from 'react';

const Scene3D = lazy(() => import('./Scene3D'));

function App() {
  return (
    <Suspense fallback={<div>Loading 3D...</div>}>
      <Scene3D />
    </Suspense>
  );
}
```

**Reduce Complexity on Mobile**
```jsx
import { useThree } from '@react-three/fiber';

function AdaptivePixelRatio() {
  const { gl } = useThree();

  useEffect(() => {
    const isMobile = /iPhone|iPad|Android/i.test(navigator.userAgent);
    if (isMobile) {
      gl.setPixelRatio(1.5);
    }
  }, [gl]);

  return null;
}
```

## 3D Performance Rules

### Budgets

| Metric | Target | Maximum |
|--------|--------|---------|
| Initial load | < 500KB | < 1MB |
| Frame rate | 60fps | 30fps minimum |
| Draw calls | < 100 | < 500 |
| Triangles | < 50K | < 200K |
| Textures | < 4MB total | < 10MB |

### Optimization Strategies

**1. Geometry**
- Use low-poly models
- Implement LOD (Level of Detail)
- Merge static geometries
- Use instancing for repeated objects

**2. Textures**
- Compress textures (Basis/KTX2)
- Use appropriate sizes (power of 2)
- Mipmap for distance
- Lazy load textures

**3. Lighting**
- Limit dynamic lights
- Use baked lighting when possible
- Ambient occlusion textures

**4. Shaders**
- Profile complex shaders
- Use simpler materials on mobile
- Avoid fragment shader heavy effects

**5. Rendering**
- Use `requestAnimationFrame` correctly
- Pause when not visible
- Reduce frame rate for background scenes

## Mobile Considerations

### Degradation Strategy

```javascript
function get3DQuality() {
  const isMobile = /iPhone|iPad|Android/i.test(navigator.userAgent);
  const hasLowGPU = navigator.hardwareConcurrency < 4;

  if (isMobile || hasLowGPU) {
    return {
      particleCount: 100,
      geometryDetail: 'low',
      shadowsEnabled: false,
      pixelRatio: 1
    };
  }

  return {
    particleCount: 1000,
    geometryDetail: 'high',
    shadowsEnabled: true,
    pixelRatio: Math.min(window.devicePixelRatio, 2)
  };
}
```

### Touch Interactions

```jsx
import { GestureDetector, Gesture } from '@use-gesture/react';

function InteractiveModel() {
  const bind = Gesture({
    onDrag: ({ offset: [x, y] }) => {
      // Rotate model based on drag
    },
    onPinch: ({ offset: [scale] }) => {
      // Zoom model
    }
  });

  return <Canvas {...bind()} />;
}
```

## Graceful Fallbacks

### WebGL Not Supported

```jsx
function Scene3D() {
  const [webglSupported, setWebglSupported] = useState(true);

  useEffect(() => {
    try {
      const canvas = document.createElement('canvas');
      const gl = canvas.getContext('webgl') || canvas.getContext('experimental-webgl');
      setWebglSupported(!!gl);
    } catch (e) {
      setWebglSupported(false);
    }
  }, []);

  if (!webglSupported) {
    return <StaticImageFallback />;
  }

  return <Canvas>...</Canvas>;
}
```

### Reduced Motion

```css
@media (prefers-reduced-motion: reduce) {
  .floating-element {
    animation: none;
  }

  .parallax-element {
    transform: none !important;
  }
}
```

## Common 3D Patterns

### Product Showcase

```jsx
function ProductModel({ modelUrl }) {
  return (
    <Canvas camera={{ position: [0, 0, 5], fov: 50 }}>
      <ambientLight intensity={0.5} />
      <spotLight position={[10, 10, 10]} angle={0.15} penumbra={1} />
      <Suspense fallback={null}>
        <Model url={modelUrl} />
        <Environment preset="studio" />
      </Suspense>
      <OrbitControls enableZoom={false} />
    </Canvas>
  );
}
```

### Particle Background

```jsx
function Particles({ count = 500 }) {
  const positions = useMemo(() => {
    const pos = new Float32Array(count * 3);
    for (let i = 0; i < count; i++) {
      pos[i * 3] = (Math.random() - 0.5) * 10;
      pos[i * 3 + 1] = (Math.random() - 0.5) * 10;
      pos[i * 3 + 2] = (Math.random() - 0.5) * 10;
    }
    return pos;
  }, [count]);

  return (
    <points>
      <bufferGeometry>
        <bufferAttribute attach="attributes-position" count={count} array={positions} itemSize={3} />
      </bufferGeometry>
      <pointsMaterial size={0.02} color="#ffffff" />
    </points>
  );
}
```

### Scroll-Linked 3D

```jsx
import { useScroll, useFrame } from '@react-three/fiber';
import { useRef } from 'react';

function ScrollModel() {
  const ref = useRef();
  const scroll = useScroll();

  useFrame(() => {
    if (ref.current) {
      ref.current.rotation.y = scroll.offset * Math.PI * 2;
    }
  });

  return <mesh ref={ref}>...</mesh>;
}
```

## Common Mistakes

❌ **3D for the sake of 3D**
- Must serve a purpose
- Content over effects

❌ **Ignoring mobile performance**
- Test on real devices
- Implement degradation

❌ **No fallbacks**
- WebGL may not be available
- Provide static alternatives

❌ **Excessive particle counts**
- Destroys mobile performance
- Use 100-500 for mobile, 1000-5000 for desktop

❌ **Heavy textures**
- Compress and optimize
- Use appropriate sizes

❌ **Complex shaders on low-end devices**
- Profile before shipping
- Provide simpler alternatives

## Quick Reference

**CSS 3D for:**
- Simple depth effects
- Card flips
- Subtle tilts

**Three.js/R3F for:**
- Complex scenes
- Product visualization
- Immersive experiences

**Performance:**
- Lazy load 3D content
- Reduce complexity on mobile
- Provide fallbacks
- Respect reduced motion

**Testing:**
- Test on real mobile devices
- Monitor frame rates
- Profile with DevTools

---

3D should enhance the experience, not define it. Use intentionally, optimize relentlessly.

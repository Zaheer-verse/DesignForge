# Code of Conduct

## Our Standard

DesignForge welcomes constructive contributions from people with different backgrounds, skill levels, and perspectives. We expect participants to be respectful, specific, and collaborative.

Examples of positive behavior:

- Giving actionable feedback
- Assuming good intent while still naming issues clearly
- Respecting maintainers' time
- Keeping discussion focused on the project
- Welcoming newcomers and explaining context

Examples of unacceptable behavior:

- Harassment, threats, or personal attacks
- Discriminatory language or behavior
- Publishing private information without permission
- Repeatedly derailing technical discussions
- Spam or low-effort disruption

## Enforcement

Maintainers may remove comments, close issues, reject contributions, or block participants who violate this code of conduct. Enforcement should be proportional, consistent, and focused on maintaining a healthy project environment.

## Reporting

Report conduct issues through the repository owner's preferred public contact method or GitHub moderation tools. Do not include sensitive personal information in public issues.
